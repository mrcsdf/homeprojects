Use this as your quick guide:

| Project          | Use it for                                                | Good starter prompt                                                     |
| ---------------- | --------------------------------------------------------- | ----------------------------------------------------------------------- |
| **Research Lab** | Deep research, comparisons, fact-checking, current topics | “Research this thoroughly and cite the strongest sources.”              |
| **Development**  | Coding, debugging, architecture, automation               | “Diagnose the root cause first, then give me the smallest correct fix.” |
| **Life HQ**      | Planning, priorities, home projects, decisions, errands   | “Turn this into a realistic plan with clear next actions.”              |
| **Finance**      | Budgeting, investing, retirement, taxes, major purchases  | “Model this decision, show assumptions, and recommend the best option.” |

**Rule of thumb:**

* Need evidence? → **Research Lab**
* Need code? → **Development**
* Need a plan? → **Life HQ**
* Need money analysis? → **Finance**

You can also just ask naturally—the project instructions will do most of the heavy lifting.
